Install

install.sh copies themes into ~/.config/omarchy/themes. It installs all 5 variants of a theme unless you pick some with --variant. It never replaces a theme that you made.

One theme, all 5 variants, no clone

$ curl -fsSL https://bjarneo.github.io/100-themes/install.sh \
    | bash -s -- synthwave --set

One variant only

$ curl -fsSL https://bjarneo.github.io/100-themes/install.sh \
    | bash -s -- synthwave --variant oled --set

All 500 themes

$ git clone --depth 1 https://github.com/bjarneo/100-themes ~/.local/share/100-themes
$ ~/.local/share/100-themes/install.sh --all
$ omarchy theme set synthwave-oled

Apply with Aether

Select a theme and a variant, then select Apply with Aether. Aether downloads colors.toml and a 3840×2160 copy of the background, then applies them at once. Install as Omarchy theme adds the variant to the Omarchy theme picker.

Variants: dark, day, high-contrast, day-high-contrast and oled. Other options: --all, --list, --update, --remove, --link and --force. Run install.sh --help for details.

The palettes come from the Neon ANSI Palette design. The day and high contrast variants keep each hue and chroma and change only the lightness. High contrast colors reach 7:1, the WCAG AAA level. OLED variants use a pure black background.

Backgrounds are drawn with canvas scripts in tools/. Omarchy is at omarchy.org.
